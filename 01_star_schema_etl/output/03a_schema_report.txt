======================================================================
  4) เกร็ดของ SQLite ที่ต้องรู้
======================================================================
INTEGER PRIMARY KEY มีความหมายพิเศษ
  เขียนแบบนี้เป๊ะ ๆ คอลัมน์จะกลายเป็น alias ของ rowid ซึ่งเป็นตัวชี้
  ตำแหน่งจริงในไฟล์ ค้นหาเร็วสุดโดยไม่ต้องสร้าง index เพิ่ม
  แต่ถ้าเขียน INT PRIMARY KEY จะไม่ได้ผลนี้ กลายเป็น index ธรรมดา

SQLite ไม่มีชนิดข้อมูล DATE
  ต้องเก็บวันที่เป็น TEXT รูปแบบ ISO8601 เท่านั้น เพราะเรียงตามตัวอักษร
  แล้วได้ลำดับเวลาถูกต้องพอดี

  ISO8601    : ['2026-01-15', '2026-02-03', '2026-04-24', '2026-12-01']
  DD/MM/YYYY : ['01/12/2026', '03/02/2026', '15/01/2026', '24/04/2026']
  อันหลังเรียงตามวันที่ ไม่ใช่ตามปี ใช้ WHERE เทียบช่วงเวลาไม่ได้

UNIQUE บน email กับ product_name เป็นตาข่ายชั้นสุดท้าย
  เรา dedup ไว้แล้วใน 2A แต่ถ้าโค้ดตรงนั้นพังวันหนึ่ง ฐานข้อมูลจะปฏิเสธเอง
