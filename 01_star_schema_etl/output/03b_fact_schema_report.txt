  1) เปิดการตรวจสอบ foreign key
======================================================================
ค่าเริ่มต้นตอนเปิด connection : foreign_keys = 0
หลังสั่ง PRAGMA               : foreign_keys = 1

ถ้าไม่สั่งเปิด คำสั่ง FOREIGN KEY ที่เขียนไว้ใน CREATE TABLE จะเป็นแค่
ข้อความประกอบ ไม่บังคับอะไรเลย ใส่ customer_id = 9999 ที่ไม่มีจริงก็เข้าได้

และค่านี้ไม่ถูกจำไว้ในไฟล์ ต้องสั่งใหม่ทุกครั้งที่เปิด connection
แปลว่า step3c กับ step4 ต้องสั่งเองด้วย

======================================================================
  3) สร้าง fact_sales
======================================================================
  cid  name          type      notnull  pk
  0    order_id      TEXT      1        1
  1    customer_id   INTEGER   1        0
  2    product_id    INTEGER   1        0
  3    date_key      INTEGER   1        0
  4    quantity      INTEGER   1        0
  5    unit_price    REAL      1        0
  6    amount        REAL      1        0

order_id ได้ notnull = 1 เพราะเขียน NOT NULL กำกับไว้
ถ้าเขียนแค่ TEXT PRIMARY KEY เฉย ๆ SQLite จะยอมให้ NULL เข้ามาจริง ๆ
(PostgreSQL กับ MySQL ตั้ง PK เป็น NOT NULL ให้อัตโนมัติ SQLite ไม่ทำ)

======================================================================
  4) foreign key ที่สร้างไว้
======================================================================
  id   คอลัมน์ใน fact ตารางปลายทาง     คอลัมน์ปลายทาง
  0    date_key       dim_time         date_key
  1    product_id     dim_product      product_id
  2    customer_id    dim_customer     customer_id

                dim_customer
                     |
                     | customer_id
                     v
dim_time  <----- fact_sales ----->  dim_product
        date_key            product_id

======================================================================
  5) index บนคอลัมน์ FK
======================================================================
  idx_fact_date                    unique=0  สร้างเอง
  idx_fact_product                 unique=0  สร้างเอง
  idx_fact_customer                unique=0  สร้างเอง
  sqlite_autoindex_fact_sales_1    unique=1  อัตโนมัติจาก PK

SQLite ไม่สร้าง index ให้ FK เองแบบ MySQL ถ้าไม่สร้างจะเจอสองปัญหา
  join กับ dimension ทีไรต้องสแกน fact ทั้งตาราง
  ลบหรือแก้แถวใน dimension ต้องสแกน fact ทั้งตารางเพื่อเช็คว่ามีใครอ้างอิงอยู่
